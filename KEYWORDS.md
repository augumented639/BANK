## 5. On-Page Placement Rules Enforced
1. **Title Tag:** Exactly 50–60 characters. Primary keyword in front or natural position, followed by format and brand identifier.
2. **Meta Description:** 120–155 characters. Benefit-first with action-oriented phrasing.
3. **Heading Hierarchy:** Exactly one `<h1>` per page reflecting the primary keyword, followed by clean logical `<h2>` steps, features, security notes, and `<h3>` FAQ items.
4. **First 100 Words:** Primary keyword included naturally within the opening two sentences.
5. **URL Slugs:** Lowercase, hyphen-delimited, matching search queries without filler words.
6. **Internal Links:** Every page interlinked within 3 clicks via header navigation, breadcrumbs, related tools section, and structured footer groups.
7. **Truthful Content:** No manufactured ratings, review counts, or certifications.
